# 团队作业3：系统设计与实现

## 校园活动报名与签到管理系统

---

## 一、系统架构设计

### 1.1 整体架构
采用前后端分离的轻量级架构：
- **前端**：移动端H5页面（HTML/CSS/JavaScript），适配手机浏览器
- **后端**：RESTful API 接口
- **数据库**：MySQL 关系型数据库
- **部署**：云端服务器，支持全校学生访问

### 1.2 技术栈
| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Vue3 + Vant UI | 移动端组件库，适合快速开发 |
| 后端 | Node.js + Express | 轻量级Web框架，开发效率高 |
| 数据库 | MySQL 8.0 | 关系型数据库，适合结构化数据 |
| 接口 | RESTful API | JSON数据格式，前后端分离 |
| 部署 | 云服务器 + Nginx | 反向代理，静态资源分发 |

## 四、模块详细设计

### 4.1 用户模块
**功能描述**：用户登录、信息管理、角色权限控制

**核心流程**：
1. 学生用学号+姓名登录系统
2. 系统验证学号是否存在，匹配姓名
3. 登录成功后返回用户信息和token
4. 根据角色（学生/管理员）显示不同功能界面

### 4.2 活动模块
**功能描述**：活动的发布、展示、管理

**核心流程**：
1. 管理员填写活动信息，提交发布
2. 系统将活动存入数据库，状态设为"报名中"
3. 学生在首页浏览活动列表，支持按分类筛选
4. 学生点击活动查看详情

### 4.3 报名模块
**功能描述**：活动报名、取消报名、报名状态管理

**核心流程**：
1. 学生在活动详情页点击"立即报名"
2. 系统检查活动是否还在报名期、是否还有名额
3. 符合条件则创建报名记录，状态为"已报名"
4. 学生可在"我的活动"中查看报名记录
5. 活动开始前可取消报名

### 4.4 签到模块
**功能描述**：二维码生成、扫码签到、签到统计

**核心流程**：
1. 活动开始前，管理员生成动态签到码
2. 学生到达现场，打开"我的活动"，出示签到码
3. 管理员扫码验证，或者学生扫描现场的签到码
4. 系统验证签到码有效性，更新报名状态为"已签到"
5. 管理员可查看活动的签到统计数据

## 五、核心界面实现

### 5.1 前端页面清单
1. **首页（活动列表）**：Banner、搜索框、分类标签、活动卡片列表
2. **活动详情页**：活动封面、基本信息、报名进度、活动介绍、报名按钮
3. **我的活动页**：Tab切换（待参加/已结束）、活动列表
4. **签到页**：我的签到码、扫码签到入口
5. **活动发布页（管理员）**：活动表单、提交按钮

### 5.2 已实现的原型
- 高保真HTML原型已完成，包含上述核心界面
- 支持页面切换、报名交互、签到模拟
- 适配移动端尺寸，可在手机浏览器直接打开
